# Example Stand Information Table

A subset of FIA data for just one plot in western Montana. These data
come from the FVS_STANDINIT_PLOT table in the MT database and have been
processed using
[`get_FVS_ready()`](https://sprachan.github.io/FVSIE-tools/reference/get_FVS_ready.md)
with the option "add_identifiers" set to TRUE.

## Usage

``` r
ex_stand
```

## Format

### `ex_stand`

A data frame with 1 rows and 34 columns.
