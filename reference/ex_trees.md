# Example Tree list

A subset of FIA data for just one plot in western Montana. These data
come from the FVS_TREEINIT_PLOT table and have been processed using
[`get_FIA_state()`](https://sprachan.github.io/FVSIE-tools/reference/get_FIA_state.md)
with the option "add_identifiers" set to TRUE.

## Usage

``` r
ex_trees
```

## Format

### `ex_trees`

A data frame with 51 rows and 31 columns.
